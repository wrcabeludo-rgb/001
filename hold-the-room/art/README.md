# Векторная графика (SVG)

Сюда загружаются SVG-файлы базовой графики: герой (`hero-sit.svg`, `hero-play.svg`, `hero-rock.svg`),
душа (`soul.svg`), зрители (`viewer-1.svg` … `viewer-6.svg`), боссы и дебошир (`critic.svg`, `rival.svg`,
`fear.svg`, `drunk.svg`), сцены залов (`stage-1.webp` … `stage-5.webp`, растр 1:2, край сцены — в `STAGE_ART` в game.js). Промпты и требования — в DESIGN.md.
