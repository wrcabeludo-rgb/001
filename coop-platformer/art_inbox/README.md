# Папка для новых артов

Сюда загружаются готовые картинки (png, jpg, webp) и ролики (mp4) прямо через сайт GitHub:
**Add file → Upload files**, затем **Commit changes** (в ветку `claude/coop-platformer-design-b3x619`).

Называйте файлы как в заголовках промптов (`gunner_death_1.png`, `power_rage.png`, `swordsman_shock_run.mp4`…).
Если имя другое — не страшно, разберусь по картинке.

После подключения файлы переезжают в `art_source/`, а эта папка снова пустеет.
