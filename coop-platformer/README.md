# Неон и пепел

Кооперативный платформер на Godot 4: стрелок и мечник. Вся концепция описана в [CONCEPT.md](CONCEPT.md).

## Как скачать и запустить сборку (Windows)

1. Откройте на GitHub вкладку **Actions** → **Coop Platformer build**.
2. Выберите верхний запуск с зелёной галочкой.
3. Внизу страницы, в разделе **Artifacts**, скачайте `CoopPlatformer-windows`.
4. Распакуйте архив и запустите `CoopPlatformer.exe`.

Windows может предупредить о неизвестном издателе: нажмите «Подробнее» → «Выполнить в любом случае».

## Как открыть проект в редакторе

1. Скачайте **Godot 4.4.1 (Standard, не .NET)**: https://godotengine.org/download/archive/4.4.1-stable/
2. Запустите Godot → **Import** → выберите файл `coop-platformer/game/project.godot`.
3. Нажмите **F5**, чтобы запустить игру.

Параметры движения героев меняются без кода:
- **в игре:** клавиша **F1** открывает панель с ползунками; кнопка «Скопировать значения» кладёт числа в буфер обмена;
- **в редакторе:** двойной щелчок по `resources/heroes/shooter_movement.tres` или `swordsman_movement.tres`, числа меняются в инспекторе справа.

## Управление

| | Левая клавиатура | Правая клавиатура | Геймпад |
|---|---|---|---|
| Бег / направление | A D W S | Стрелки | Стик или крестовина |
| Прыжок | K или Пробел | Num 2 | A |
| Атака | J | Num 1 | X |
| Навык | L | Num 3 | B |
| Доп. действие | I | Num 5 | Y |
| Start | Esc | Num Enter | Start |

На геймпаде PlayStation: A = ✕, X = □, B = ○, Y = △, Start = Options.

## Что в игре сейчас

**Мир 1** из трёх зон: **1-1 «Трущобы»**, **1-2 «Затопленное метро»**, **1-3 «Главный сток»** с боссом «Хозяин стока».
Главное меню: продолжить, новая игра (выбор сложности → комикс → 1-1), выбор открытых зон, магазин, настройки.
После каждой зоны — итоги (время, тайники, лом, падения) и **лавка старьёвщика**: оружие и улучшения за лом
(у каждого героя свой лом и свои покупки). После 1-3 — комикс конца мира.

- **Start** во время игры — пауза: продолжить, настройки, отключить игрока, выйти в меню.
- **Сохранение** автоматическое: после каждой зоны и каждой покупки. Лом, собранный в зоне, сохраняется только при выходе с зоны.
- **Стрелок:** доп. — сменить оружие (дробовик покупается в лавке).
- **Усилители** (редко выпадают из врагов и лежат в тайниках): «Я» — ярость (урон ×2), «Щ» — щит, «С» — скорость.
- **Тайники:** в каждой зоне два места, где пол или стена ненастоящие.

**Тестовые уровни** в меню открывают тестовую комнату.

Присоединиться: прыжок или Start на свободном устройстве. Выйти: Start → «Отключить игрока».
**Вниз + доп.** меняет героя на любом уровне (пока игра тестируется). Если второй герой занят напарником, игроки меняются героями.
**Вниз** на земле — присесть: герой ниже пуль на уровне груди, стрелок стреляет низко (по мелким врагам), мечник рубит низко. **Вниз + прыжок** — спрыгнуть с площадки. У лестницы **вверх / вниз** — лезть, **прыжок** — отпустить. На канат достаточно запрыгнуть.

**F2** переключает тестовые сцены по кругу: тестовая комната → «Полигон» (враги) → «Мастерская» (механики уровня). На уровне «Трущобы» F2 открывает тестовую комнату.

| Герой | Движение | Атака | Навык | Доп. |
|---|---|---|---|---|
| Стрелок | бег, прыжок, прыжок от стены, **двойной прыжок** | выстрел в 8 направлениях; держать и отпустить — заряженный выстрел (тратит патроны) | пинок | — |
| Мечник | бег, прыжок, прыжок от стены | серия из 3 ударов; вверх + атака — удар вверх | **рывок** | держать — **блок** |

## Структура

Карты зон собираются скриптами `tools/levels/*.py` (они же проверяют, что всё достижимо без двойного прыжка):
`python3 tools/levels/slums.py --png preview.png`.

```
game/
  project.godot           настройки проекта
  scenes/                 сцены: меню, комиксы, зоны 1-1…1-3, лавка, тестовые уровни
  assets/audio/           звуки и музыка (создаются tools/audio_synth.py)
  resources/heroes/       параметры движения и боя героев
  scripts/core/           ввод, игроки, сложность, звук, сохранения, товары лавки
  scripts/player/         герой, его движение и атаки
  scripts/combat/         урон, здоровье, зоны ударов, снаряды
  scripts/enemies/        враги и босс
  scripts/level/          сборка уровня из текстовой карты, камера, контрольные точки
  scripts/mechanics/      платформы, лифты, лестницы, опасности, бочки, двери, арены
  scripts/targets/        манекены и турель для тренировки
  scripts/ui/             меню, комикс, панели героев, полоса босса, итоги
  scripts/debug/          панель настройки (F1)
  tests/                  автоматические проверки
  scripts/test_room.gd    тестовая комната
```
