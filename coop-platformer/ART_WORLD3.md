# Арт для мира 3 — «Башня „Люмена"»

Каждый промпт — **целиком**: стиль, описание, поза, технический блок. Копируй как есть. Что приложить —
написано над промптом. Готовые файлы — в папку `coop-platformer/art_inbox/` на GitHub (или в чат).

**Порядок:** тайлы → враги → фоны → механизмы → босс → комиксы. Пока картинок нет, уровни работают на заглушках.
