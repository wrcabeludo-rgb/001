# «Неон и пепел» — концепция кооперативного платформера

> Рабочий документ. Собран по блокам в формате «вопрос → решение».
> Статус: этапы 0–6 готовы. Сейчас — полный мир 1: три зоны, мета-игра, звук; графика по мере готовности картинок (ART_WORLD1.md).

---

## Блок 1. Платформа и техническая база ✅

| Параметр | Решение |
|---|---|
| Платформа | PC: Windows + Linux (заодно Steam Deck) |
| Движок | Godot 4 (полноценный рендерер), язык GDScript |
| Разрешение | Базовое 1920×1080, масштабирование под 1440p / 4K |
| Управление | Клавиатура и геймпад, все клавиши переназначаются |
| Кооператив: устройства | Клавиатура + геймпад, два геймпада, двое за одной клавиатурой |
| Аудитория | Для себя и друзей |
| Роли | Код полностью пишет Claude, автор тестирует и принимает решения |
| Графика | Сначала заглушки, затем ИИ-генерация с доработкой |
| Язык игры | Русский |

**Следствия:**
- Две раскладки на одной клавиатуре: игрок 1 на WASD плюс клавиши рядом, игрок 2 на стрелках плюс цифровой блок. Нужно проверить, сколько одновременно зажатых клавиш регистрирует клавиатура.
- Рисованная ИИ-графика плохо даёт покадровую анимацию, поэтому персонажей и врагов делаем в технике cutout-анимации (кукла из частей, анимируется в Godot). Подробности в блоке 7.

## Блок 2. Кооператив и режимы ✅

| Параметр | Решение |
|---|---|
| Режимы | Одиночная игра (выбор героя) или кооператив на двоих на одном экране |
| Камера | Отдаляется при расхождении героев. На максимальном отдалении стоит на месте, боковые и верхняя границы — жёсткие стены. Поводка и телепорта нет. |
| Падение за нижний край | Считается смертью и ведёт к возрождению по правилам ниже |
| Смерть одного в кооперативе | Автовозрождение рядом с напарником через несколько секунд |
| Смерть обоих / одиночки | Возврат к последней контрольной точке |
| Второй игрок | Подключается и выходит в любой момент кнопкой Start |
| Кооп-головоломки | Нет: кооператив только в бою, уровни проходимы любым героем в одиночку |
| Выбор героев | Каждый выбирает своего, герои обязательно разные |
| Сложность | Выбор в меню: лёгкая / нормальная / сложная |
| Ресурсы | У каждого игрока свои |

## Блок 3. Персонажи ✅

**Сеттинг:** постапокалиптический киберпанк. Руины неонового мегаполиса после катастрофы: мутанты, сбесившиеся роботы, остатки корпораций, оружие из подручных материалов.

### Стрелок
- Прицеливание в 8 направлениях.
- Стреляет только на бегу, отдельной стойки для стрельбы с места нет.
- Базовое оружие бесконечное и слабое. Патроны, выпадающие из врагов, тратятся на мощные выстрелы.
- Заряженный выстрел: зажал и отпустил кнопку — мощный пробивающий выстрел (тратит патроны).
- Ближний бой: пинок, отталкивающий врага.
- Передвижение: двойной прыжок.

### Мечник
- Комбо из 3 ударов на земле и удар вверх.
- Защита — блок: пока кнопка зажата, урон снижается.
- Передвижение: рывок сквозь врагов.

### Общее
- Здоровье — полоска; разные враги наносят разный урон.
- Лечение только аптечками, выпадающими из врагов.
- Командных приёмов нет: герои воюют рядом, но независимо.

## Блок 4. Уровни и окружение ✅

| Параметр | Решение |
|---|---|
| Структура | Последовательные уровни |
| Контрольная точка | Только сохраняет место: не лечит, ничего не восстанавливает |
| Длина уровня | 15–25 минут, 2–3 контрольные точки |
| Боссы | Уровни сгруппированы в миры по 3–4 уровня, в конце мира босс |
| Платформы | Односторонние, движущиеся, рушащиеся, лифты, лестницы и канаты |
| Опасности | Шипы, кислота или радиоактивная жижа, лазеры по таймеру, падающие обломки, огнемётные турели |
| Урон от опасностей | Урон и отбрасывание (из ямы с кислотой или шипами отбрасывает вверх и в сторону, чтобы можно было выбраться) |
| Возрождение на КТ | После смерти герой возрождается на контрольной точке с полным здоровьем |
| Стены | Прыжок от стены (у обоих героев) |
| Интерактивные объекты | Взрывающиеся бочки, укрытия, двери |
| Секреты | Скрытые комнаты с улучшениями |

## Блок 5. Враги ✅

**Фракции:** мутанты, роботы и дроны, люди (мародёры или корпоративная охрана), распределены по мирам.

**Типы врагов:**

| Тип | Поведение |
|---|---|
| Ходок | Патрулирует, атакует вблизи |
| Дрон | Летает, пикирует или стреляет сверху |
| Турель | Стоит на месте и стреляет очередями |
| Тяжёлый | Медленный, бронированный, сильный удар |
| Рывковый | Мигает перед атакой и делает резкий рывок |
| Засадник | Прыгает с потолка или вылезает из-под земли |

| Параметр | Решение |
|---|---|
| После смерти героев | Все враги после контрольной точки возрождаются |
| Выпадение предметов | Забирает тот, кто первым коснулся; патроны подбирает только стрелок |
| Окружение | Взрывные бочки ранят и врагов |
| Арены | Посреди уровня двери закрываются, нужно отбиться от волны или элитного врага |
| Боссы | Чередуются: арена с 2–3 фазами атак и погони по разрушающемуся уровню |
| Предупреждение об атаках | Чёткое: вспышка или заметный замах перед ударом |

## Блок 6. Прогрессия ✅

| Параметр | Решение |
|---|---|
| Скрытые комнаты | Постоянные улучшения характеристик (+макс. здоровье, +запас патронов, +урон) |
| Кто получает улучшение | Только тот, кто нашёл. Улучшение бесполезное для этого героя (например, +патроны у мечника) превращается в полезное ему (например, +прочность блока) |
| Валюта и магазин | Из врагов выпадает «лом», между уровнями открывается магазин улучшений. Кошелёк у каждого героя свой |
| Оружие стрелка | Несколько видов оружия открываются по ходу (дробовик, лазер, гранатомёт) и переключаются кнопкой; плюс временные усилители в стиле Contra. Базовое оружие бесконечное, остальные тратят патроны |
| Развитие мечника | Разные мечи с разными свойствами |
| Сохранения | Один профиль, автосохранение после каждого уровня. Прогресс (улучшения, оружие, лом) хранится отдельно для каждого героя |
| Повторное прохождение | Пройденные уровни можно перепроходить через меню выбора |
| Сюжет | Короткие экраны-комиксы между мирами. Сюжет «Неон и пепел» с выбором в финале — см. [STORY.md](STORY.md) |

**Баланс:** уровни проходимы без улучшений, улучшения только облегчают игру (прогресс у героев раздельный, один может отстать).

| Параметр | Решение |
|---|---|

| Анимация | Сначала cutout (кукла из частей в Godot); для главных героев позже, возможно, покадровая |
| Фон | Многослойный параллакс |
| Освещение | Динамический 2D-свет: неон, выстрелы и взрывы освещают окружение |
| «Сочность» боя | Умеренная: тряска экрана, микропаузы, искры. Ползунок «тряска экрана» в настройках |
| Музыка | Синтвейв или дарксинт; бесплатные библиотеки и ИИ-генерация |
| Звуковые эффекты | Бесплатные библиотеки и ИИ-генерация |
| HUD | В углах экрана: игрок 1 слева сверху, игрок 2 справа сверху. Здоровье, патроны, оружие, лом |

## Блок 8. План разработки ✅

Каждый этап заканчивается сборкой, которую автор запускает и проверяет. Следующий этап начинается после обратной связи.

| # | Этап | Что получится | Как проверить |
|---|---|---|---|
| 0 | Каркас проекта | Проект Godot в репозитории, управление для двух игроков (клавиатура и геймпады) | Запускается, серый квадрат бегает |
| 1 | Движение | Оба героя (серые фигуры): бег, прыжок, прыжок от стены, двойной прыжок у стрелка, рывок у мечника. Тестовая комната | Прыгать приятно; параметры подкручиваются в настройках |
| 2 | Бой | Стрелок: 8 направлений, базовое оружие, заряженный выстрел, пинок. Мечник: комбо, удар вверх, блок. Здоровье, урон, отбрасывание. Манекены для тестов | Бить и стрелять приятно |
| 3 | Кооператив | Второй игрок по кнопке Start, камера с отдалением и жёсткими краями, смерть за нижним краем, возрождение рядом с напарником, контрольные точки | Вдвоём играть удобно, камера не мешает |
| 4 | Враги | Ходок, дрон, турель → тяжёлый, рывковый, засадник. Выпадение аптечек, патронов и лома | Каждый враг читается и честно побеждается |
| 5 | Механики уровня | Платформы, лифты, лестницы, опасности, бочки, укрытия, двери, арены | Всё работает в тестовой комнате |
| 6 | **Вертикальный срез** | Один полный уровень в серой графике (15–25 мин) + арена + первый босс. Выбор сложности | **Главная веха:** полноценный уровень, в который интересно играть |
| 7 | Мета-игра | Меню, выбор героя, выбор уровня, сохранения, магазин, оружие стрелка, мечи, усилители, секретные комнаты, настройки и переназначение клавиш | Полный цикл «уровень → магазин → уровень» |
| 8 | Графика и звук | Пробы стиля через ИИ, первый герой в cutout, фон с параллаксом, свет, музыка и звуки. Заменяем заглушки в вертикальном срезе | Срез выглядит и звучит как настоящая игра |
| 9 | Контент | Мир 1 (мутанты, трущобы, босс-арена), мир 2 (роботы, завод, босс-погоня), мир 3 (корпорация, небоскрёб, финальный босс). Комиксы между мирами | Игра проходится от начала до конца |
| 10 | Полировка и сборки | Баланс, исправление ошибок, готовые сборки для Windows и Linux, проверка на Steam Deck | Готово к игре с друзьями |

| Параметр | Решение |
|---|---|
| Порядок этапов | Утверждён, как в таблице |
| Первая полная версия (v1.0) | Только мир 1: 3–4 уровня + босс. Миры 2 и 3 в следующих версиях |
| Сборки для проверки | Готовый `.exe` для Windows после каждого этапа + проект открывается в редакторе Godot для подстройки параметров |
